Что это за проект?

Freddy Fazbear — это десктопное приложение для управления парком аттракционов. Система позволяет продавать билеты, вести базу данных посетителей и аттракционов, а также просматривать статистику продаж и выручки.

Проект разработан на Python с использованием Tkinter для интерфейса и SQLite для хранения данных. Подходит как учебный проект по базам данных и графическим интерфейсам.

Продажа билетов

Детский, взрослый и семейный билеты с привязкой к аттракционам

Статистика

Продажи, выручка, средний чек

База данных

Просмотр, фильтрация, сортировка и добавление записей

Мобильное приложение

Покупка билетов, список аттракционов и тарифов
